## 优化项（按 收益/风险 排序）

### P1 匹配算法：按模式长度分层（收益大，测试覆盖充分）

| 长度 | 现状 | 改为 |
| --- | --- | --- |
| 1B | 逐字节比较 | `bytes.index_byte` 循环（SIMD AVX2/NEON）；-i 时交替查两个大小写形式 |
| 2..16B（bndm 槽位） | naive | **memchr 预筛 + 倒序验证**：`index_byte` 找首字节，命中再比剩余 |
| 17..64 / >64 | naive | 同上（稀疏数据下 O(n/m) 次验证） |

- 重叠命中必须保留（`"aa"` in `"aaa"` → 2 条）：候选位置逐 1 推进即可。
- 空模式 / 超长模式 / 越界：与 naive 完全一致（现有测试覆盖）。
- `bndm_match` 仍是"未实现位并行"，改委托 `memchr_match` → 需更新 README 契约 #3。

### P2 多模式：首字节 bitmap 预筛（收益大，风险低）

`multi_match` 当前 O(n × Σ|pat|)。加 256-bit 首字节集合（4×u64），
当前字节不在集合内就直接跳过。-i 用 lower 形式建表。

### P3 Output_Queue 改环形缓冲（收益中，风险中）

现状出队是"整体左移 + pop"，队列堆积时 O(n²)。改为 head/count 环形，
仅在满时扩容重排。并发测试（4 生产者 × 250 条 + FIFO）覆盖。

### P4 silent 操作跳过实时输出队列（收益中，风险中）

`--quiet` / `--count` / `-l` / `-L` 时明细不打印，但仍逐条 push+pop（带 mutex）。
改为：silent 且 `-m` 未设置时 worker 不 push，命中数由归并结果得出。
**必须保持契约 #14**：`-m` 取"流式到达顺序"前 N 条 → 只在 max_count==0 时启用。

### P5（备选，视前四项结果）行号表稀疏化 / 输出批量写

- `build_line_index` 当前存每个换行偏移（O(行数) 内存）→ 每 64 行存一个锚点。
- 输出线程逐条 `fmt.printf`（每条一次 write）→ 攒批 flush（**风险**：与进度条
  `\r` 交错可能改变输出文本，需 golden 验证）。

## 红线

- 命中集合、顺序（归并后）、计数、dump 内容**必须与优化前逐字节一致**；
  只有"流式打印的到达顺序"允许因提速而变化（golden 用 --quiet/小文件规避）。
- 不改契约：重叠窗口重复上报、多模式同偏移各报一条、空模式无命中。
